Informasi Umum

BookVault menyediakan REST API lokal untuk membaca, menambah, mengubah, dan menghapus data buku dari database SQLite.

Endpoint POST, PUT, dan DELETE wajib menggunakan API key pada header: 

X-API-Key: bookvault-api-key-123
