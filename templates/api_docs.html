Developer Reference

BookVault REST API

Interface JSON untuk membaca dan mengelola katalog buku lokal BookVault. Endpoint baca tersedia tanpa API key, sedangkan operasi mutasi dilindungi melalui header X-API-Key.

Lihat endpoint ↓
Endpoints {{ endpoints|length }} route API terdokumentasi
Public Read 3 tanpa API key
Protected Write 3 memerlukan X-API-Key
Format JSON request dan response API

Authentication

API key untuk operasi write

POST · PUT · DELETE

Tambahkan API key yang dikonfigurasi pada environment BookVault ke header request. Nilai key tidak ditampilkan di dokumentasi.

Header
X-API-Key
Environment
BOOKVAULT_API_KEY
Failure
401 Unauthorized
Request header 
X-API-Key: <YOUR_API_KEY>
Content-Type: application/json

GET /api/books
Public

Mengambil koleksi buku lokal. Query parameter dapat digunakan untuk pencarian judul/penulis dan filter genre.

ParameterTypeRequiredFungsi
qstringTidakMencari judul atau penulis.
genrestringTidakMemfilter berdasarkan genre.
Example request 
GET /api/books?q=dazai&genre=Japanese%20Literature
GET /api/books/<id>
Public

Mengambil satu buku berdasarkan ID.

200 Book ditemukan 404 Book not found
POST /api/books
API key required

Menambahkan buku baru ke katalog lokal. Field title, author, genre, dan year wajib diisi.

JSON body 
{
  "title": "No Longer Human",
  "author": "Osamu Dazai",
  "genre": "Japanese Literature",
  "year": 1948,
  "rating": 4.4,
  "description": "Novel tentang alienasi, identitas, dan kehancuran psikologis.",
  "cover_image": ""
}
201 Created 400 Invalid input 401 Invalid API key 409 Duplicate book
PUT /api/books/<id>
API key required

Memperbarui data buku berdasarkan ID. Field yang tidak dikirim mempertahankan nilai sebelumnya.

JSON body 
{
  "title": "No Longer Human Updated",
  "rating": 4.6,
  "description": "Data buku diperbarui melalui endpoint PUT."
}
200 Updated 400 Invalid input 401 Invalid API key 404 Book not found 409 Duplicate book
DELETE /api/books/<id>
API key required

Menghapus buku berdasarkan ID. Favorite yang mereferensikan buku tersebut ikut dihapus sebelum record buku dihapus.

200 Deleted 401 Invalid API key 404 Book not found
